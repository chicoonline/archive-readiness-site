# Archive Readiness Check

A browser page that checks which photos carry the metadata an archive needs: creator, rights, caption, keywords, date, place, alt text, title, credit and licence. It reads EXIF, IPTC and XMP, flags conflicts between them, and writes ExifTool commands that fill only empty fields.

Photos never leave the browser: only their metadata is read, on your own device.

Live: https://archivereadiness.chicomorais.com
