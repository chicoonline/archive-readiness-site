    Fill what's the same on every photo
    
    
    Creator, copyright, credit and licence are the same on all your own photos, so one command can fill them in a whole folder. It uses ExifTool, a free program for your Mac. It fills only fields that are empty, so nothing you've written is overwritten, and it keeps a backup of every file. Caption, keywords and location differ per photo; do those in Lightroom.
    
    
    
      
      
    
    
    
      
      
    1. Install ExifTool once: in Terminal, brew install exiftool (with Homebrew), or the macOS package from exiftool.org.
      2. 
      
    2. Work on a copy of the folder first. In Terminal, type cd  (with a space), drag the folder onto the window, and press Return.
      3. 
      
    3. Paste the commands below and press Return. They run one after another, on that folder only, not its subfolders.
      4. 
      
    4. Check a few photos, then run the check on this page again. When you're happy, delete the backup files ending in _original.
      5. 
    
    
    
    
    
    
    
    What it does: (1) fills creator, copyright with the year the photo was taken, credit line and licence link wherever they're empty, in XMP, IPTC and EXIF at once, with IPTC text saved as UTF-8 so © stays ©; (2) adds a copyright line without a year where there's no date taken; (3) replaces camera defaults such as “NIKON USER” in the creator field. Tested with ExifTool 13.60.

    Limits
    
    
      
      
    • Raw files: metadata in a matching .xmp sidecar is read when you choose the folder, or select both files. Metadata kept only in the Lightroom catalogue isn't: in Lightroom, select the photos and use Metadata › Save Metadata to Files first.
      • 
      
    • "Filled" means a value exists. Whether it's right (the correct species, the right beach) is still for a person to check.
      • 
      
    • Location counts as filled with either a place name or GPS coordinates. Place names are read from the older IPTC fields (Sublocation, City, State, Country) and from the newer Location Created and Location Shown, which is where Lightroom Classic's "Location Created" goes.
      • 
      
    • Text a camera writes on its own, such as GoPro's DCIM\100GOPRO, isn't a caption: it's marked "check", not "filled".
      • 
      
    • Older IPTC text is sometimes stored in the wrong character set. The check repairs the common case (© shown as Â©) before comparing.
